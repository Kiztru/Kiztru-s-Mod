# Kiztru’s Mod
A lightweight FF14-inspired content mod for Minecraft.

Kiztru’s Mod adds a selection of FF14-themed swords, tools, blocks, and music discs to enhance gameplay while remaining balanced and fully compatible with vanilla survival.

## Features
- FF14-inspired tools
- New tool sets
- Custom fantasy blocks
- Collectible music discs inspired by Final Fantasy XIV
- Vanilla-friendly design

![Items](https://github.com/user-attachments/assets/4ae68288-eea2-4d59-9f08-b1e8312d4897)

## Compatibility
- Works in singleplayer and multiplayer
- Designed to avoid conflicts with other mods
- Does not modify Minecraft visuals or core systems
