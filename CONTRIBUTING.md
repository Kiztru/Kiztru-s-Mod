# Contributing to Kiztru’s Mod

Thank you for your interest in contributing! All help is appreciated.

### License

By contributing, you agree that your code and assets will be released under the **MIT License**.


## Getting Started

### 1. Fork & Clone
```bash
git clone https://github.com/Kiztru/Kiztru-s-Mod.git
cd Kiztru-s-Mod
```

### 2. Create a Branch
```bash
git checkout -b feature/your-change
```

### 3. Build & Test

Ensure you have the correct Java version for the mod’s MC version.

Run:
```bash
./gradlew build
./gradlew runClient
./gradlew runServer
```

## Make sure:

- The game launches without errors

- No assets are missing

- No mixin conflicts occur

### Submitting a Pull Request

- Clearly describe what you changed and why

- Keep commits clean and well-named

- Ensure the project still builds successfully

### Code Style

- Follow standard Java conventions

- Use meaningful names

- Remove unused imports

- Avoid commented-out code

- Keep methods small and readable
